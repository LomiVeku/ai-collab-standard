# 条款修订单

> 版本 v1.5｜2026-10-20｜适用范围：本规范全集｜上位文件：README（铁律）

## 这张表是干什么的

**不是流程，是后路。**

规范里的每一条，都有它被写下来的那一刻。那一刻的起因、当时的判断、验没验过——如果只散落在版本说明、评审记录和某次会话里，那么**一旦上下文或记忆被整理、次要文档被当成"只保留核心思路"而剔除，这些条款就再也无法溯源**。条款要升降级时，会失去唯一的依据，只能凭印象判断"这条还成不成立"。

所以这张表只有一个用途：**让每一条规则的来历能独立成立**。

### 第二层作用：它降低了修订的门槛（但不是标准）

没有这张表时，改一条规则的真实成本**不只是改字**——还要承担"以后没人说得清为什么改"的风险。于是理性的选择是**不改**，规范就在"怕改坏"里慢慢僵化：条款越积越多，越积越不敢动，最后变成一堆没人知道来历、也没人敢碰的条文。

有了一表可查，这层阻力消失了。**所以它真正放宽的是"修订的门槛"——让规范敢改、能改、改完还说得清。**

但必须同时说清界限：**放宽的是门槛，不是标准。**

| | 变化 |
|---|---|
| **改动的阻力** | **下降**——有据可查，不怕改了说不清，也不怕被追问"当初为什么这么定" |
| **落笔的成本** | **上升**——每次改都要写清"为什么改、怎么验的"，含糊的改动在表里会立刻显形 |
| **判据的严格度** | **不变**——〔R〕仍是红线，D-11 仍要双向验证，不能因为"有记录"就把验的程序省掉 |

换句话说：**它把成本从"改之后"挪到了"改之前"。** 以前是改完再担心说不清，现在是改之前就得想清楚。**门槛低到敢动手，标准高到不能乱动——这两件事必须同时成立，缺一个都会坏。**

**自足原则**（本表唯一的硬要求）：每一行的「为什么」与「检验方式」必须**不依赖任何外部文档也能读懂**。最后一列「深挖指针」是加分项——它指向原始报告，但**即使那些报告全部丢失，本表仍然能回答"这条为什么存在、验没验过"**。

### 第三层作用：它让"反推"成为可能

正向读规则，只能知道它**要求什么**；反向读这张表，才能知道它**当初在解决什么**、那个前提**还在不在**。

前提消失了，规则就该改或该降级——但在没有来历的情况下，"这条还成不成立"只能凭印象，而凭印象的判断既无法说服别人，也无法被复核。有了一行来历，"退休"和"保留"都能给出理由。

这也解释了一个常见现象：**已经解决过的问题被重新讨论一遍**。不是记性差，是没有地方能查到"这个问题上次怎么定的、谁推翻的"。本表的存在就是为了让同一个判断**不被反复论证**——这是填坑备忘录那条原则（不重复解决同一个问题）在**规则层**的延伸：**不重复论证同一个判断，也是不重复。**

## 记什么、不记什么

| 记 | 不记 |
|---|---|
| 新增条款 | 措辞微调、错别字、标点 |
| 修改判据（改的是"怎么判"） | 纯格式调整（换行、表格对齐） |
| 删除、降级、放宽、收紧 | 同义改写（判据未变） |
| 级标变更（〔R〕/〔G〕/〔P〕互转） | 举例、排版、章节挪位 |
| 附录与模板的结构性变动 | |

**何时记**：改的当批就记，**不攒批**。攒批等于把"以后补"变成"永远不补"，而这项记录的保质期恰好是"当事人还记得的时候"。

## 三、待登记与失效条件

- **失效条件**：若本表连续 **3 个版本**没有新增行，而同期规范确有条款改动，则判定本表已失效——此时应**删除本表**，而不是留一张假的"溯源"让人误以为有据可查。**一张不可信的表比没有表更危险。**
- **与 D-11 的关系**：本表登记"检验方式"，但**不构成 D-11 的履行证明**。D-11 要求「非作者用已知好样本必通过 + 已知坏样本必失败」的双向验证，针对**检查脚本**；本表写的"仅文本审阅"就是如实记录"没做脚本验证"，不得据此声称已过 D-11。
- **待办**：T-21 若将来落成脚本检查项，须补做 D-11 双向验证，并在本表新增一行登记其结果。
