# 示例说明

本目录存放**真实项目中的实例**，用于对照格式与颗粒度，**不构成规范条文**。

## 决策记录-待办提醒窗-20261019.md

- **来源**：一个真实项目的 `docs/决策记录.md`，照录未改写（该项目的其他文件未随本仓库公开）。
- **性质**：某桌面待办工具项目的六条决策（DR-001～DR-006），其中 DR-003 是**失败案例**——原判把"3 字节 BOM 的空文件"当成通过证据，后来被推翻；DR-004 记录的是"规范本身被复核后如何修订"，包含一次对复核方事实指控的驳回；DR-005 是**本条规范 v1.2 自己的来历**（规则僵硬治理：不加条文、改结构）；DR-006 是**v1.3 那条回流规则的来历**——它演示了该放项目内还是通用规范这个判断本身怎么被记下来。
- **为什么收录**：决策档案最容易在两个地方走样——**写成流水账**，或者**只写结论不写代价**。直接看一份真实条目，比读十条要求更快校准颗粒度。
- **看什么**：
  1. 「选项与代价」是否具体到能让读者反驳；
  2. 「失效条件」是否可判定（出现什么就重开）；
  3. 「证据指针」是否指得回原始文件，而不是"已验证"；
  4. 失败案例是否**保留原判**，而不是改写成"经过充分考虑"。
- **注意**：其中的版本号、哈希、路径均属该项目，其他项目套用方法即可，不要照抄结论。
